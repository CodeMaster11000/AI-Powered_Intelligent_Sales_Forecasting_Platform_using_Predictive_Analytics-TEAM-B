# Database design

Keep all schema design artifacts here (Milestone 1 Prep, Day 3):

- ER diagram (export as PNG/PDF plus the editable source, e.g. draw.io / dbdiagram)
- Table definitions and the data dictionary (column, type, nullable, meaning)
- Constraints and indexes decisions (what is unique, what is a foreign key)
- Lifecycle stage rules (which stage changes are allowed)

Source of truth for the entities is SRS section 2.4.
